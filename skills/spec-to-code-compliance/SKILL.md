# Specification-to-code compliance

Use when a task asks whether code implements a specification, contract, ADR, or
formal design. Extract requirements before comparing them with code; cite the
document section and exact file/line evidence for every mapping. Never infer
missing requirements. Classify each item as full match, partial match,
mismatch, missing, or undocumented behavior, with a confidence level.
