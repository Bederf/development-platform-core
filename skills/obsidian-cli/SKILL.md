# Obsidian CLI

Use the CLI only when the Obsidian desktop application is open. Run
`obsidian help` first when command syntax is uncertain. Quote values containing
spaces and preserve the vault's existing note authority. Report clearly when
the desktop application or CLI is unavailable.
