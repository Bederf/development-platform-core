# Obsidian Flavored Markdown

Use Obsidian-compatible Markdown when editing notes in the project vault.

- Put valid YAML properties at the top when the note needs metadata.
- Use `[[wikilinks]]` for vault notes and normal Markdown links for external URLs.
- Use `![[...]]` embeds and `> [!type]` callouts when they improve the note.
- Preserve existing properties and links unless the requested change includes them.
- Verify syntax and links after editing; do not treat a presentation artifact as
  more authoritative than the source note.
