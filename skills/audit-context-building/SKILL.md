# Audit context building

Use before deep audits when architecture or call-flow understanding is
uncertain. Map modules, entrypoints, actors, state, trust boundaries, data
flows, invariants, and external interactions from the code and authoritative
documents. Trace important calls across module boundaries and record
uncertainty explicitly. This skill builds context; it does not itself assert
vulnerabilities, severity, or fixes.
