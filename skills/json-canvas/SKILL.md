# JSON Canvas

Use this skill only for `.canvas` files or requested visual canvases. Preserve
the JSON Canvas 1.0 shape (`nodes` and `edges`), generate unique node and edge
IDs, and ensure every edge references existing nodes. Validate JSON and all
references after every change.
