# Capability Definition v1 Examples

These examples prove that the same contract family can describe two unrelated
contexts without consumer-specific branches:

- a static software library; and
- a robotics controller.

Each file is an informative example wrapper containing a `documents` array.
The wrapper is not a platform contract. Every array item independently
validates against `contracts/capability-definition.v1.schema.json`.

The examples use only fake identities and implementations. They do not select
a provider, framework, protocol, database, service, or consumer repository.
